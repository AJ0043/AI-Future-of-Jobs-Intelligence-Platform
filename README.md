# 🧠 About The Project

## 🌍 Understanding The Future Of Work Through Data

**AI Future of Jobs – Intelligence Platform** is an end-to-end **Data Analytics project** focused on understanding how the global job market is evolving across industries, locations and job roles.

The project analyzes **30,000 job records and 13 features** covering current employment conditions and projected job openings between **2024 and 2030**.

The analysis combines:

* 💼 Job-market demand
* 💰 Salary intelligence
* 🤖 AI impact
* ⚙️ Automation risk
* 🔮 Future job demand
* 🏠 Remote work
* 🎓 Education requirements
* 🧑‍💻 Experience requirements
* 🌎 Geographic differences
* 👥 Gender diversity

The goal is not simply to visualize the dataset, but to answer meaningful **business and workforce questions using data**.

# 🧮 Feature Engineering

A major derived metric will be:

### 📈 Opening Growth %

```python
ai_data['Opening_Growth_%'] = (
    (
        ai_data['Projected Openings (2030)']
        - ai_data['Job Openings (2024)']
    )
    / ai_data['Job Openings (2024)']
) * 100
```

This allows the project to compare:

**Current openings → Future openings → Percentage change**

Additional derived metrics may be introduced when analytically useful.
